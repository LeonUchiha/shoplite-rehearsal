# ShopLite Checkout

Demo product repository for **Session C3 - Shipping & Sharing**.

- `src/`, `test/` - the product (Feature-1 cart subtotal; Feature-2 coupons on `feature/FEAT-2-coupons`)
- `docs/stories/` - user stories with acceptance criteria
- `docs/review-checklist.md` - the committed C2 review checklist
- `.claude/` - C2/C3 workflow as **standalone repo customizations** (Claude Code)
- `.github/prompts`, `.github/agents` - the same workflow for GitHub Copilot in VS Code
- `.mcp.json` / `.vscode/mcp.json` - GitHub MCP server config (token comes from your environment, never from a file)

Run tests: `npm test`
